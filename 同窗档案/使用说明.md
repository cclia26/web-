# 小组成员介绍

首页固定展示五位组员。点击姓名或照片即可进入个人页，点击「返回组员索引」回到首页。

## 去哪里填

在 VS Code 打开网站文件夹，从 index.html 预览网站。点击「填写资料」，在同一页依次填写五个人的姓名、专业、年级、兴趣、一句话简介，并选择各自的照片。例如，兴趣可以填「摄影、游泳」，简介可以写「我喜欢用相机记录校园生活」。所有人的内容都保存在 scripts/team-data.js。

## 怎样保存

通过 VS Code Live Server 打开时，点击「保存并预览」可以在当前浏览器查看填写效果。要分享或提交，点击「导出资料文件」，用下载的 team-data.js 替换 scripts 文件夹中的同名文件，再打包整个网站。照片已包含在导出的文件中。直接双击 HTML 打开时，也可以用这个导出方式保存。

## 文件位置

index.html 是首页，member-1.html 到 member-5.html 分别是五个个人页，edit.html 是统一填写页。页面共用 styles/main.css。scripts/main.js 读取成员资料并更新页面，scripts/editor.js 处理表单与照片。
